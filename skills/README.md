# Reusable design skills

These are upstream skill files saved locally for reuse. Ask an agent to read
the relevant `SKILL.md` before a design task.

- [Frontend Design](frontend-design/SKILL.md) — intentional visual direction,
  typography, layout, and visual review.
  Source: https://github.com/anthropics/skills/blob/main/skills/frontend-design/SKILL.md
- [Web Design Guidelines](web-design-guidelines/SKILL.md) — interface review.
  Source: https://github.com/vercel-labs/agent-skills/blob/main/skills/web-design-guidelines/SKILL.md
  Its current rules are saved in [command.md](web-design-guidelines/command.md).
  The upstream skill asks reviewers to fetch fresh rules on each review.

Downloaded on 2026-10-29. The skill files are preserved as downloaded; the
Frontend Design license is included alongside its skill.
